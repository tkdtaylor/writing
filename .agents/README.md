# `.agents/`: Antigravity workspace customizations

Antigravity (IDE, App and the `agy` CLI) discovers workspace customizations in `.agents/`. This repo's agent roles, slash commands and hooks are **authored once, for Claude Code**, in `.claude/`. Those files are managed by the create-project skill, so see `.claude/skill-manifest.json` before editing them.

Everything here adapts those canonical files for Antigravity:

| Path | What it is | Surfaces |
|---|---|---|
| `skills/claude-compat/` | Hand-written translation layer: Claude tool names, `$ARGUMENTS`, sub-agent dispatch, which hooks run | IDE, App, CLI |
| `skills/<role>/` | Generated skill adapter for `.claude/agents/<role>.md` (inline use) | IDE, App, CLI |
| `skills/<command>/` | Generated skill adapter for `.claude/commands/<command>.md` (invoke as `/<command>`) | IDE, App, CLI |
| `agents/<role>.md` | Generated custom subagent: canonical role body as system prompt, Claude tools and model mapped | App, CLI |
| `hooks.json`, `hooks/claude_hook_adapter.py` | Runs the safety hooks from `.claude/scripts/` (no-commit-on-main, protect-checkout, block-no-verify, protect-secrets, config-protection, spec-coverage-check) and retro injection | CLI and App (verified in the CLI) |

## Keeping them in sync

```bash
scripts/sync-agy-skills.py          # (re)generate skills and subagents after .claude/ roles/commands change
scripts/sync-agy-skills.py --check  # exit 1 if anything is missing, stale, or orphaned
```

Don't edit generated files by hand (they carry a `generated by` marker). Change the generator or the canonical `.claude/` file instead. The hook adapter has no generated parts; if `.claude/settings.json` gains a new safety hook, add it to `hooks.json`.

Hook profiles work the same as in Claude Code: set `CLAUDE_HOOK_PROFILE` or `CLAUDE_DISABLED_HOOKS` in the environment that launches Antigravity.
